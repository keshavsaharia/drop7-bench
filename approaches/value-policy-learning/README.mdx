Train a model to answer "how good is this board?" or "which column here?" from
example games, then play by its judgment. This family tried value models,
policy networks, DQN variants, distillation from stronger teachers, and
sibling-advantage rankers.

## The recurring failure: sibling extrapolation

A model trained on played games learns the outcome of the action that **was**
played. At deployment it must rank several actions it has **never** seen
equally well. Low error on visited states did not translate into good
root-action ranking:

## What the evidence showed

- Played-action value error is **not** action-ranking accuracy. Training data
  must cover every legal sibling, or the objective must target relative action
  value directly.
- The denoised public value passed its prediction gates and produced a small
  confirmation gain — the best learned-value result — but confidence stayed
  weak and no protected cohort was opened.
- This failure mode is exactly what the
  [afterstate-learning](/approaches/afterstate-learning) family was designed
  to fix with successor-closed, action-complete labels.
